Guidelines · Usage & Best Practices
Logo Usage
✓ Do

Use logo.png (default) on light backgrounds. Use LogoBlack.png on dark backgrounds. Maintain a minimum clear space equal to the logo height on all sides.

✗ Don't

Stretch, skew, rotate, or recolor the logo. Place it on busy/noisy backgrounds where contrast drops below 3:1. Crop or remove the mark from the wordmark.

Color Guidelines

Primary Palette — Always Lead With These

  • Accent (#9E4A2A) for headings, primary buttons, active links, and key visual anchors
  • Ink (#2A1B14) for all body text — never use a lighter gray for long-form readability
  • Paper (#FAF3E9) as the default page background — it sets the warm tone
  • Sand (#E7CFB4) for secondary backgrounds, card fills, and subtle containers

Secondary Palette — Use Intentionally

  • Blue (#0081F3) for interactive CTAs only (links, buttons that need contrast)
  • Azure (#1168C8) reserved for info badges / role tags — do not use for body text
  • Peach (#E9C6B4) as a gradient partner — do not use as a standalone text color
  • Accent Light (#F4E2D6) for tag/pill backgrounds — pairs with Accent text
  • Espresso (#1A0E0C) only for extreme contrast moments (hero overlays, dark mode)

Accessibility

  • Accent on Paper passes AA at 16px+ — do not use Accent on Sand (fails contrast)
  • Ink on Paper passes AAA — safe for all body copy
  • Ink Muted on Paper passes AA at 16px+ — use only for secondary text (captions, metadata)
  • Blue on Paper passes AA — do not use Blue on Surface or Sand
  • Always test interactive states (hover, focus, disabled) against WCAG 2.1 AA

Dark Background

  • On dark backgrounds, use the dark logo variants (LogoBlack.png / FullLogoThemeDark.png)
  • Swap text to Peach (#E9C6B4) or Sand (#E7CFB4) for readability
  • Never use Ink or Ink Muted on dark backgrounds — they disappear
  • Accent remains usable on dark backgrounds but pair with a lighter companion
Typography Guidelines

Roboto Slab (Display)

  • Weight 700 only — never use 500 or 400
  • Reserved for hero headings (2.4rem) and section titles (1.15rem)
  • Do not use in body copy, navigation, or buttons
  • Letter-spacing: 0 (default) — do not add tracking

Inter (Body)

  • 400 (Regular) for body paragraphs
  • 500 (Medium) for emphasized body / navigation
  • 600 (Semibold) for labels, uppercase metadata
  • 700 (Bold) sparingly — inside cards or short callouts
  • Uppercase labels use 600 weight · 0.05em letter-spacing · Accent color

Hierarchy

  • H1: 2.4rem Roboto Slab 700 · Ink
  • H2/Section Title: 1.15rem Roboto Slab 700 · Ink
  • H3: 0.95rem Inter 600 · Ink
  • Body: 0.95rem Inter 400 · Ink
  • Secondary/Caption: 0.82rem Inter 400 · Ink Muted
  • Label: 0.75rem Inter 600 uppercase · 0.05em · Accent

Line Length & Spacing

  • Max line length: 70–80 characters (≈ 600–680px for body)
  • Body line-height: 1.6 · Caption line-height: 1.55
  • Paragraph margin-bottom: 1rem (16px)
  • Never use justified alignment — always left-align
Component Guidelines

Buttons

  • .btn-primary: Accent bg · white text · 20px pill radius · 6px 16px padding
  • .btn-outline: Transparent bg · 2px Border stroke · Ink text · 8px radius
  • Hover: shift to Accent Strong for primary · fill accent for outline
  • Disabled: reduce opacity to 0.4 — do not change color

Cards & Containers

  • Use Surface (#EFE1CF) for card backgrounds inside Paper pages
  • Border: 1px solid Border (#E3D0BA)
  • Radius: 12px (md) for cards, 16px (lg) for modals/sheets
  • Padding: 1rem 1.25rem for compact cards, 2.5rem for spacious layout

Tags & Badges

  • .tag: Accent Light bg · Accent Strong text · 20px pill · 5px 14px
  • .badge-primary: Accent bg · white text · 12px radius · uppercase
  • .badge-secondary: Azure bg · white text · 12px radius · uppercase
  • .badge-ghost: Accent Light bg · Accent Strong text · 12px radius · uppercase
  • Badges are always uppercase — tags are sentence case

Spacing Rhythm

  • Section margin-bottom: 2.5rem (40px)
  • Grid gap: 1rem (16px) for tight grids, 1.5rem (24px) for loose
  • Inner card padding: 1rem (16px) compact · 1.25rem (20px) standard
  • Section divider: 2px gradient line with 1rem top / 2rem bottom margin
  • Always use multiples of the 4px grid for internal spacing

Quick-Start

New project setup

  • Copy the CSS variables above into your :root block
  • Import Google Fonts: Inter (400,500,600,700) + Roboto Slab (500,700)
  • Set body background to var(--paper), text to var(--ink)
  • Reference the logo assets from ./assets/img/logo/
  • Follow the spacing rhythm (4px grid, 16px/24px/40px increments)

Tailwind integration

  • Map CSS variables to theme.extend.colors in tailwind.config
  • Use bg-[var(--accent)] or named tokens after configuration
  • Font family: Inter as sans, Roboto Slab as serif/display
  • Border radius: extend with sm: 8px, md: 12px, lg: 16px, xl: 20px, pill: 9999px
